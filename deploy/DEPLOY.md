# نشر خادم مدار (منصة متعددة المدارس)

نظام التخزين: خادم Node.js صغير يحفظ بيانات كل مدرسة معزولة تماماً في
SQLite على نفس السيرفر، ويزامنها لحظياً بين الأجهزة عبر SSE. أي عدد من
المدارس يمكنه استخدام نفس الرابط — كل مدرسة تسجّل حسابها الخاص (اسم
مستخدم وكلمة مرور مستقلين) ولا ترى بيانات مدرسة أخرى إطلاقاً.

هذا النشر **مستقل تماماً** عن أي مشروع آخر على نفس الجهاز (مجلد مختلف،
منفذ باك-إند مختلف، قاعدة بيانات مختلفة). راجعي `CLAUDE.md` لتفاصيل
المسارات الحالية.

## الخطوات (على السيرفر، كـ root)

### 1) اسحب آخر تحديث
```bash
cd /var/www/madar-new && git pull origin main
```

### 2) شغّل سكربت الإعداد (مرة واحدة، أو أعد تشغيله بأمان لتحديث النسخة)
```bash
bash /var/www/madar-new/deploy/setup.sh
```
يثبّت Node، اعتماديات الخادم، يولّد **مفتاح مزوّد الخدمة** (PLATFORM_TOKEN)،
يشغّل الخدمة (`madar-new-api` على المنفذ 3010)، ويجدول نسخة احتياطية يومية.
سيطبع `PLATFORM_TOKEN=...` — **احفظي هذا المفتاح في مكان آمن**، فهو مفتاح
لوحة تحكم مزوّد الخدمة (إدارة كل المدارس) ولا يمكن استرجاعه من الواجهة لاحقاً.

### 3) إعداد nginx
انسخي محتوى `deploy/nginx-madar.conf` إلى `/etc/nginx/sites-available/ma-dar`
(أو أنشئيه يدوياً بنفس المحتوى)، ففّليه، ثم:
```bash
ln -sf /etc/nginx/sites-available/ma-dar /etc/nginx/sites-enabled/ma-dar
nginx -t && systemctl reload nginx
```

### 4) شهادة SSL
```bash
certbot --nginx -d ma-dar.solutions -d www.ma-dar.solutions
```

### 5) إدارة المدارس من لوحة مزوّد الخدمة
افتحي `https://ma-dar.solutions/#provider` وأدخلي مفتاح مزوّد الخدمة
(PLATFORM_TOKEN من الخطوة 2). من هناك:
- **إضافة مدرسة يدوياً** (اسم مستخدم/كلمة مرور تُنشئينها أنتِ)، أو
- **تفعيل مدرسة سجّلت نفسها** من صفحة الموقع (تظهر بحالة "قيد المراجعة")
- لكل مدرسة: نوع العضوية (روضة / حضانة - دار ضيافة / مدرسة بكل مراحلها)،
  ومدة الاشتراك (الفصل الأول/الثاني/العام كاملاً/أشهر محددة) وتواريخه،
  وحالة الحساب (نشطة/قيد المراجعة/موقوفة).
- عند إيقاف مدرسة أو انتهاء تاريخ اشتراكها، تُمنع من الدخول لبياناتها
  تلقائياً حتى تُفعَّل مجدداً.

⚠️ لوحة مزوّد الخدمة عامة الوصول (على نفس رابط الموقع) لكنها محمية
بالمفتاح السرّي فقط — لا تشاركي هذا الرابط أو المفتاح مع أحد غير موثوق.

## التحقق
- `curl -s http://127.0.0.1:3010/api/health` → `{"ok":true,"tenants":N,...}`.
- `systemctl status madar-new-api` → active (running).
- النسخ الاحتياطي: `/var/backups/madar/`.

## أوامر مفيدة
```bash
systemctl restart madar-new-api     # إعادة تشغيل الخدمة
journalctl -u madar-new-api -n 50   # سجل الخدمة
/usr/local/bin/madar-backup.sh      # نسخة احتياطية فورية
```
